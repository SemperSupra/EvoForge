# EvoForge

[Open EvoForge](https://sempersupra.github.io/EvoForge/)

## Releases and reproducible research

The [release-source branch](https://github.com/SemperSupra/EvoForge/tree/release-source) contains the curated source, MIT license, locked dependencies, complete golden fixtures, user guide and containerized build/test instructions. No AI tool, account or private repository is required.

[Public qualification runs](https://github.com/SemperSupra/EvoForge/actions) report the exact tested revision, native build and golden results, browser capability measurements and release evidence. A release candidate is not the currently deployed version. The live site is replaced only after the candidate's required gates pass and it is marked for promotion.

This default branch retains the previously deployed static site and the bounded publication workflow. No development or exploratory history is mirrored here. Contributions remain invite-only.
