# R63 visual learning editorial and qualification policy

Use motion when the sequence itself is the concept (motion prediction and constraint correction; genetic selection; state transitions). Use direct manipulation when the relationship is spatial or numerical (Voronoi, polygon crossing, aspect ratio, symmetry, RGB interpolation). Use still diagrams for stable data structures, and recorded, captioned native demonstrations when authentic system behavior matters (e.g. creature movement or a meteor countdown/impact). Every demonstration distinguishes a teaching simplification from the production renderer, offers a text explanation and uses opt-in motion; reduced-motion preference uses single steps. Do not autoplay, fetch third-party media or request a GPU while reading. No external video added in R63: first capture verified output, write a transcript, and prefer brief clips demonstrating a concrete behavior over promotional montage. Never attribute a teaching illustration to 3Blue1Brown or reproduce its assets. Each demo must explain limitation, cause, consequence and investigation, including numerical, representational, device and search boundaries. Physical device and actual visual review remain part of the release hold.
